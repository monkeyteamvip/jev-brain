What Jev is

State + typed questions.
Structured answers. Nothing else.

Jev does not write text or code. You send what’s true right now and explicit questions. It returns branches you can execute in Python — Choice, Score, or Noul.

Choice

Pick one

Which worker, which folder, which next action. Labeled options. One winner.

Score

Rate it

Ordered labels — urgency, quality, lead heat. A calibrated scale, not a paragraph.

Noul

Yes / no + confidence

Publish? Escalate? Delete? Binary with calibrated probability — not vibes.

Architecture

Three jobs. Stop mashing them into one API call.

If it creates → LLM. If it picks / scores / gates → Jev. If it does the thing → code.
